# GRAM 数字典藏平台

面向手机端的静态前端演示原型，展示 Telegram 礼物图鉴、典藏管理、出租/生息模拟、GRAM 铸造池和深浅主题切换。

## 本地预览

直接在浏览器中打开 `index.html` 即可。

## 演示说明

- 礼物图片引用 Fragment 的公开目录预览。
- 典藏品添加、出租、生息和收益领取仅保存在当前浏览器的 `localStorage` 中。
- 铸造池、充值和转出均为本地演示，不连接钱包、不发起链上交易，也不托管真实 NFT 或资产。
- 演示收益参数不代表实际租赁条件、利率或收益承诺。

## 项目文件

- `index.html`：页面结构与内容
- `styles.css`：响应式布局、玻璃风格和深浅主题
- `app.js`：页面交互及本地演示状态
- `favicon.svg`：网站图标
